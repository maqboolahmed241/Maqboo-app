# Dukaan Hisab Android App

This repository is intended for the **Dukaan Hisab V14** Android APK build.

The Android project should package the original `Maqbool_Munir_Dukaan_Hisab_V14.html` application as `app/src/main/assets/index.html`, with the Android WebView wrapper and GitHub Actions workflow.

Build workflow: `.github/workflows/build-apk.yml`

> APK build is not yet verified. Do not treat this repository setup note as an APK download.
